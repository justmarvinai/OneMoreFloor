# Credits and third-party assets

Everything the game ships is either the owner's, licensed for commercial use, or
generated by this repository's own tooling. This file is the record of what came
from where, and what each licence asks for in return.

## FantasyUI

The component library and its art packs (`src/ui/fui/`, `public/fui/`) are
`justmarvinai/fantasyuis`, the owner's own library, vendored per
`docs/ARCHITECTURE.md` §2. Q13 confirmed every pack in it is free for commercial
use.

## Open Game Icons — slot icons

The fourteen icons in the empty gear sockets on the character sheet come from
[Open Game Icons](https://open-game-icons.net)
(`github.com/open-game-icons/icons`), a fork of `game-icons/icons`.

**Licence:** CC BY 3.0, with several contributors releasing under CC0. The CC BY
ones require attribution, which is given here and in
`public/art/slots/ATTRIBUTION.md`.

**Icons made by Lorc, Delapouite, Skoll and Willdabeast.**

They are used as masks rather than pictures: `tools/vendor-slot-icons.mjs`
strips each source file's black backdrop and repaints the glyph as
`currentColor`, so the socket can tint it with the panel's ink. The full
per-icon table, with the source path and author for each, is in
`public/art/slots/ATTRIBUTION.md`.

> **Worth the owner's attention before a wider release.** CC BY asks for
> attribution "in the manner specified by the author" — for a game, that
> normally means a credits surface a *player* can reach, not only a file in the
> repository. EA 0.1 has no credits screen, and adding one is beyond what this
> round was asked for. If the icons stay, a credits entry in the Account screen
> would close it properly.

## Fonts

Vendored with FantasyUI. No font is fetched at runtime — the game makes no
network request after its own load (Brief §21), which the smoke suite asserts.
